# 🚲 Bike Sharing Data Analysis Dashboard

## Deskripsi Proyek

Proyek ini merupakan analisis data terhadap dataset Bike Sharing untuk mengetahui pola penyewaan sepeda berdasarkan faktor waktu, musim, dan kondisi cuaca.

Analisis dilakukan melalui beberapa tahapan:
- Data Gathering
- Data Assessing
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Conclusion & Recommendation

Selain itu, hasil analisis divisualisasikan dalam dashboard interaktif menggunakan Streamlit.

---

# Dataset

Dataset yang digunakan:

**Bike Sharing Dataset**

Dataset berisi informasi jumlah penyewaan sepeda harian dengan variabel seperti:
- tanggal
- musim
- kondisi cuaca
- temperatur
- kelembapan
- pengguna casual
- pengguna registered
- total rental
